# ActGenWeb — акт приёмки-передачи из договора

Запуск: открыть `index.html` двойным щелчком (сервер не нужен) или `serve.ps1` → http://localhost:8790/

1. Перетащить договор (.docx; старый .doc конвертируется через Word, если запущено через serve.ps1).
2. Проверить найденное слева, поправить при необходимости (можно прямо в предпросмотре).
3. «Сформировать .docx» — файл проверяется и скачивается.

Шаблон: `Шаблон акта.docx` (метки `{{...}}`, список — кнопка «Метки»). Правите оформление в Word,
затем кнопка «Загрузить свой» в программе (или `make-template.ps1 -EmbedOnly` после замены template_act.docx).
## Вкладка «Договор»

Переключатель «Акт | Договор» в шапке. Вкладки разделов (АР, ОВ, ВК, СС, ЭЛ — можно добавлять «+») и «★ Общее».

- **Образец** у каждой вкладки свой: загружаете обычный договор Word (.docx, .doc через serve.ps1). Программа находит в нём стороны, номер, дату, цену (цифрами и прописью), НДС, объект, город, подписи, реквизиты и заменяет на поля `{{…}}`. Оформление и остальной текст не трогаются.
- **★ Общее** — Заказчик, объект, город. Правится один раз, меняется во всех договорах. Заказчика можно вставить текстом.
- **Исполнитель** — вставляете исходные данные текстом (паспорт, ИНН, ОГРНИП, счёт…), вид (организация / ИП / самозанятый / физлицо) определяется сам; вводная часть и блок реквизитов собираются под вид. Родительный падеж и подписи «Фамилия И.О.» вычисляются.
- **Предпросмотр** правится прямо в листе: правка текста меняет образец этой вкладки, цветные поля — по клику. «Сделать полем» — выделить любой фрагмент и сделать его полем (общим или только этого договора).
- **Проверки**: контрольные цифры ИНН, ОГРН, счёта по БИК; уникальность номеров; остатки данных образца в тексте; суммы и даты вне полей (приложения-таблицы печатаются как в образце).
- Выпуск: «Скачать .docx» или «Все договоры (ZIP)». Образцы хранятся в браузере (IndexedDB).

### Excel с карточками сторон
Файл `Карточки сторон для договоров.xlsx` (или кнопка «⇩ Excel: шаблон с данными» — выгрузит текущие данные): колонка «ОБЩЕЕ» (Заказчик, объект, город) и по колонке на раздел (АР, ОВ, ВК, СС, ЭЛ): вид исполнителя, ФИО/наименование, паспорт, ИНН, счёт, номер, дата, цена, НДС, предмет. «⇪ Загрузить Excel» заполняет все вкладки; заполненные ячейки главнее строки «Исходные данные текстом». Образец договора загружается один раз на вкладку.

### Несколько организаций
Вверху вкладки «Договор» — выбор организации (+ Новая / Переименовать / Удалить). У каждой свои «★ Общее», вкладки разделов, образцы и исполнители. При загрузке договора общие данные читаются из него; если в «Общем» уже другое — программа спросит, а на вкладке «★ Общее» остаётся таблица «Прочитано из договора» с кнопками «взять» по полям.
