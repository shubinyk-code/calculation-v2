# Гидравлическая лаборатория (HydroLabWeb)

Учебная программа для браузера: пятнадцать лабораторных стендов, которые считаются
в реальном времени по нормальным формулам гидравлики. Сделана в том же духе, что и
соседняя «Насосная лаборатория» (`PumpLabWeb`): крутите ручки — числа, картинка и
графики меняются сразу.

Открывается двойным щелчком по `index.html`. Никакой сборки, никаких зависимостей.

★ — стенды, ради которых всё и затевалось.

У каждого стенда снизу лежат готовые опыты: кнопка настраивает стенд и пишет, что
делать и на что смотреть. Под опытами — теория по этому же стенду.

## Как устроено

Плоский набор файлов, классические `<script src>`, глобальные объекты — так же,
как в остальных браузерных программах этой папки.

```
index.html          оболочка: шапка, меню групп, контейнер стендов, справка
css/app.css         оформление и тёмная тема
js/util.js          числа, свойства воды, холсты, мелочи
js/hydro.js         вся физика: трение, истечение, удар, насос, безнапорный поток, наносы
js/plot.js          графики на холстах и кольцевой буфер осциллографа
js/panel.js         панель настроек из описания полей
js/svgkit.js        сборка живых SVG-схем
js/valtec.js        настроечные таблицы клапанов VALTEC VT.054
js/app.js           каркас: список стендов, вкладки, общий цикл, опыты
js/st_*.js          по файлу на стенд
tests.html          проверки ядра (73 штуки)
serve.ps1           локальный сервер для отладки, порт 8782
```

Стенд регистрируется одним объектом: состояние, описание панели, `tick(dt)`,
`draw()`, показания, пояснения, опыты и теория. Каркас сам строит раскладку,
панель, кнопки скорости, графики и карточки опытов — поэтому файл стенда почти
целиком состоит из физики и рисования.

### Численные методы

- **Колбрук — Уайт** решается итерациями от приближения Свами — Джейна.
- **Гидравлический удар** — метод характеристик, 40 участков, Δt = Δx/a, паровые
  каверны по модели DVCM.
- **Сеть** — узловой метод Ньютона с пересчётом λ на каждой итерации.
- **Циркуляция ГВС** — рабочая точка насоса ищется делением пополам по напору
  (итерировать расход напрямую нельзя: кривая насоса вместе с подогревателем
  круче колец, и итерации расходятся), расходы колец — простыми итерациями,
  температуры — по теплопотерям СП 61.13330, увязка — Kv = G/√Δp с поиском
  положения по настроечной таблице VT.054.
- **Добегание в лотке** — кинематическая волна с дисперсией, реализованная
  каскадом линейных ёмкостей (эквивалент Маскингама — Кюнжа).
- **Наносы** — Шильдс (аппроксимация Соулсби) и Мейер-Петер — Мюллер,
  сечение считается как круг минус донный сегмент.

Анимация вынесена из цикла: у каждого стенда есть `tick(dt)` и `draw()`, а в
консоли доступен `HydroLab.advance(секунды)` — прогон модели без анимации.
Это нужно и для проверок, и потому, что в скрытой панели предпросмотра
`requestAnimationFrame` не срабатывает.

### Отладка из консоли

```js
HydroLab.group("sewer");      // переключить раздел
HydroLab.show("stack");       // открыть стенд
HydroLab.active.state         // его настройки
HydroLab.advance(30);         // прогнать 30 секунд модели
HydroLab.exp(0);              // поставить первый опыт
```

## Запуск и проверка

Обычный запуск — двойной щелчок по `index.html`.

Для отладки поднимается локальный сервер:

```
powershell -ExecutionPolicy Bypass -File serve.ps1 -Port 8782
```

Проверки ядра — `tests.html`: сверяются свойства воды, коэффициенты λ и ζ, настроечные таблицы клапанов,
табличные значения насадков, скорость ударной волны, геометрия частично
заполненной трубы, осаждение и начало движения наносов, законы подобия насоса,
а также то, что численные схемы сходятся к аналитике.

## Чего здесь нет

Это учебная лаборатория, а не расчётный комплекс. Числа правдоподобны и получены
по нормальным формулам, но проект по ним считать нельзя: нет сортамента труб,
поверочных запасов и нормативных коэффициентов одновременности.

Насосная часть нарочно короткая: подробная установка повышения давления с реле,
частотником, мембранным баком, сухим ходом, дренажными насосами и спринклерами —
в соседней программе «Насосная лаборатория» (`PumpLabWeb`).

Стенд циркуляции ГВС показывает суть на четырёх стояках. Полноценный расчёт с
произвольной схемой, поиском колец, импортом из Revit, подбором диаметров и
выгрузкой таблиц — в соседней программе «Циркуляция ГВС» (`HotWaterCirculationWeb`);
оттуда же взяты настроечные таблицы клапанов.
